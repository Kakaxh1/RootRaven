# Security Policy

## Supported Versions

Currently, only the latest `main` branch of RootRaven receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within RootRaven, please send an e-mail or private message to [Kakaxh1](https://github.com/Kakaxh1) through appropriate channels, or open a Draft Security Advisory on GitHub. Do not publicly disclose the vulnerability until it has been properly mitigated.
