# Contributing Guidelines

Thank you for your interest in contributing to **RootRaven**!

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute
1. Fork the repository on GitHub.
2. Clone the forked repository to your machine.
3. Create a new feature branch (`git checkout -b feature/amazing-feature`).
4. Commit your changes.
5. Push to the branch (`git push origin feature/amazing-feature`).
6. Open a Pull Request.

## Coding Style
- Ensure UI additions follow the existing "Black Glass / Cyber" aesthetic.
- Python code should conform to standard PEP 8 styling.
- Javascript logic should utilize native socket event structures.
